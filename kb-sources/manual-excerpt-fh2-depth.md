# Expert Sleepers FH-2 — Installation manual excerpt (demo seed)

## Mechanical installation

Mount the FH-2 in an 8HP space using the supplied screws. Do **not** force the module if it binds on the rails.

### Depth

Measured from the rear of the aluminum panel to the tallest point on the USB host assembly, the FH-2 requires **51mm of clear depth** behind the rails. Cases advertised as "skiff" with ~30–38mm clearance will **not** accept this module without modification.

Ribbon cable bend radius may add a few millimetres; leave margin near the PSU.

### Power

Connect the 16-pin Eurorack power header with the red stripe on −12V as marked. Typical draw: +12V ≈ 130mA, −12V ≈ 5mA.
